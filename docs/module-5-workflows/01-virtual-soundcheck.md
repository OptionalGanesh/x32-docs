# Prueba de Sonido Virtual

## Flujo USB 32x32
Conecta la tarjeta X-USB al DAW.
1. Ajusta el ruteo para enviar las señales de los previos locales directamente al USB (Grabación).
2. Para Virtual Soundcheck, cambia las entradas de los canales de "Local" a "Card 1-32".
3. Reproduce el multipista y ajusta la mezcla sin necesidad de la banda.
