# Red y Control OSC

## Configuración Inalámbrica
Conecta la consola a un router Wi-Fi en 5GHz. Usa direcciones IP estáticas para mayor fiabilidad.

## Aplicaciones
- **X32-Edit:** Control de PC/Mac profundo.
- **Mixing Station:** Aplicación móvil preferida por su alta personalización en FOH y Monitores.

## OSC (Open Sound Control)
La X32 es controlable completamente por OSC enviando paquetes UDP al puerto 10024.
