# Ajuste de Ganancia (Gain Staging)

## Preamp Analógico vs Trim Digital
- **Preamp:** Ajusta entre -18 dBFS y -12 dBFS.
- **Trim (Gain Split):** Permite separar la ganancia analógica del control digital en FOH/Monitores.

## Puntos de Inserción (Tap Points)
- **IN / LC:** Justo tras la ganancia.
- **Pre-EQ / Post-EQ:** Antes o después del ecualizador.
- **Pre-Fader / Post-Fader:** Antes o después del control de volumen.
