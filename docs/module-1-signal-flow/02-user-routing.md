# User Routing

A partir del firmware V4, Behringer introdujo el "User Routing".

## Bloques de 8 vs User Routing 1:1
Anteriormente (Pre-v4), el ruteo debía hacerse en bloques rígidos de 8 canales. Ahora, el parcheo permite seleccionar canales uno a uno (1:1), facilitando la mezcla de fuentes locales, stageboxes AES50 y tarjeta USB sin sacrificar entradas.
