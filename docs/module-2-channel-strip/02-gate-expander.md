# Puerta y Expansor

## Key Filters
Usa filtros en la cadena lateral de la puerta para que sólo se abra con una frecuencia específica (ej. 60Hz para el bombo).

## Attack, Hold, Release
- **Bombo:** Ataque muy rápido (1ms), Hold medio (40ms), Release rápido (50ms).
- **Voces:** Mejor usar un expansor suave en lugar de una puerta estricta para evitar cortes artificiales.
