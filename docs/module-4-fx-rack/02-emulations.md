# Emulaciones Clásicas

- **LA-2A (Leisure Compressor):** Óptimo para compresión suave y musical en voces y bajos.
- **1176 (Ultimo Compressor):** Ataque rapidísimo, ideal para aplastar cajas o paralelos de batería.
- **Fairchild:** Compresión de bus maestro o subgrupos densos.
- **TruEQ:** Ecualizador gráfico sin interacción entre bandas adyacentes para afinar salas.
