# Slots de Rack FX

## Distribución
- **Slots 1 a 4:** Optimizados para efectos de tiempo (Reverbs, Delays). Típicamente usados como envíos (Send/Return).
- **Slots 5 a 8:** Diseñados para procesadores de dinámica y ecualización gráfica. Típicamente usados como Inserciones en canales o buses principales.
